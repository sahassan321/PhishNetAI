# PhishNetAI 🛡️📧

PhishNetAI is an end-to-end phishing email detection system built with Python and machine learning.  
The project trains a Logistic Regression model to classify emails as **phishing (spam)** or **legitimate (ham)** and allows users to test emails directly from the command line.

---

## 🚀 Features

- Machine learning–based phishing detection
- Logistic Regression classifier (scikit-learn)
- Command-line interface for real-time email testing
- Jupyter Notebook for data exploration and model evaluation
- Virtual environment support
- Model persistence using joblib

---

## 🧠 Dataset

- **Source:** Email spam dataset
- **Total samples:** 5,728 emails
- **Labels:**
  - `0` → Legitimate (Ham)
  - `1` → Phishing (Spam)

Class distribution:
- Legitimate: 4,360
- Phishing: 1,368

---

## 📊 Model Performance

- **Model:** Logistic Regression
- **Accuracy:** **98.08%**
